# ПУЛЬС.Кампус

**Цифровой деканат будущего** — единое мобильное и десктопное окно для расписания, успеваемости, заявок, объявлений и общения со деканатом.

Интерфейс выполнен в Neo-Minimalism Bento UI: важная информация собрана на одном экране, темы меняются одним касанием, а ключевые сценарии доступны с мобильного в 360 px и шире. Это конкурсный концепт с вымышленными студентами и данными.

## Быстрый запуск

Одна команда:

```powershell
.\.venv\Scripts\python.exe app.py
```

Откройте `http://localhost:8000`. Docker-вариант:

```bash
docker build -t pulse-campus .
docker run --rm -p 8000:8000 -e APP_SECRET="$(openssl rand -hex 32)" pulse-campus
```

Переменные окружения:

| Переменная | Назначение | Значение по умолчанию |
|---|---|---|
| `HOST` | Адрес прослушивания | `0.0.0.0` |
| `PORT` | Порт приложения | `8000` |
| `APP_SECRET` | Секрет подписи сессионных токенов | Случайная строка при запуске |

## Автотесты

```powershell
python -m unittest discover tests
```

Тесты запускают собственный HTTP-инстанс на свободном порту и проверяют вход, роли, защиту заявок от IDOR, PBKDF2-хеши и сквозной сценарий Елена → Марина → готовая справка.
